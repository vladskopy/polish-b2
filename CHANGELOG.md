# История версий

Каждая версия — минимальное изменение, проверенное на занятиях. Принцип (Gall): работающая сложная система вырастает только из работающей простой.

## v1.0 — упаковка
- Один установщик: `curl -fsSL https://github.com/vladskopy/polish-b2/releases/latest/download/polish-b2-install.sh | bash` или скачать и `bash polish-b2-install.sh`. Повторная установка в ту же папку обновляет систему и не трогает твои данные.
- Системные файлы отделены от личных: профиль и журналы создаются при первом `/b2` и в пакет не входят.
- **CI в GitHub Actions** на macOS, Linux и Windows: тесты, сборка, установка как новый пользователь, все режимы, переустановка поверх данных. Windows работает через Git Bash: переходник `.venv/bin/python`, вывод в UTF-8, LF в скриптах.
- Лицензия MIT.
- Обновление пакета без смены версии: подробный README (идея — дополнение к преподавателю, практика не выходя из Claude Code), [JTBD.md](JTBD.md) со сценариями; в навигаторе источников — официальные ссылки вместо локальных PDF, у каждого пункта пометка «бесплатно / платно / freemium»; `tools/check_repo.py` в CI ловит битые ссылки и личное.

## v0.9 — пять частей экзамена и профиль
- Занятие = выбор одного из 5 движков ([parts/](parts/README.md)): говорение, грамматика, **слушание** (короткое видео + вопросы), **чтение** (свежая статья + вопросы), письмо (пока внутри других).
- `/b2` выбирает часть, к которой дольше всего не подходили; вайб словом важнее.
- **profile.md** — адаптивный и приватный профиль; первый запуск `/b2` — опросник из 10 вопросов.
- За день до занятия с преподавателем `/b2` предлагает `/nauczyciel`.

## v0.8 — интервальное повторение
- Лесенка Лейтнера поверх `reviews.md`: ступени 1–5 → 1 / 3 / 7 / 21 / 60 дней; один подход двигает ступень один раз.
- Одна команда `/b2` (бывший `/polski`): долг повторения ≥ 3 ошибок → повторка, иначе новое.

## v0.7 — по фидбэку первой повторки
- Несколько верных ответов в упражнении — норма. Новые ошибки из тренировки записываются. ✓* в грамматике — «верно пока только в упражнениях».

## v0.6 — доверие и преподаватель
- Проверка форм словарём Morfeusz 2 (SGJP): метки ✓ словарь / ✓ / ~ с доказательством.
- `/nauczyciel` — сводка к занятию и метрика доверия по ответам преподавателя.

## v0.5 — грамматический анализатор
- 108 пунктов грамматики B2 (G1–G108): правильно / ошибка / повторяется / обходишь / не используешь. Крючок — из слабого звена (Goldratt).

## v0.4 — без неправильных форм
- Ошибка хранится как пропуск с подсказкой в скобках + ответ + исправленная фраза.

## v0.3 — журнал повторений
- `reviews.md`: строка на каждое повторение; контекст ошибки в исправленном виде.

## v0.2 — повторка
