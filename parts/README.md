# 5 частей экзамена — 5 движков

Занятие = выбор одного из движков. Выбирает `/b2` (`tools/draw.py --plan`): долг повторения → грамматика; иначе — та часть, к которой дольше всего не подходили. Вайб словом важнее: «новое», «повторка», «слушать», «читать», «коротко».

Сдать B2 = **≥ 60% в каждой из пяти частей** — поэтому каждая часть должна получать время, а не только любимая.

| Часть | На экзамене B2 (формат 2025–2026; правила 2027 ещё не опубликованы) | Движок в системе | Где описан | Статус |
|---|---|---|---|---|
| **Mówienie** | Z1 фото + тема · Z2 текст + мнение · Z3 позиция по спорному тезису | разговор по 2 подтемам с грамматическим крючком | `/b2`, режим «новые темы» | ✅ v0.1 |
| **Gramatyka** | 8 закрытых заданий: причастия, предлоги, залог, склонение, вид, числительные, степени, трансформации | повторка своих ошибок по лесенке + крючки из слабого звена | [`/powtorka`](../.claude/skills/powtorka/SKILL.md), [grammar.md](../grammar.md) | ✅ v0.2–0.8 |
| **Słuchanie** | 5 заданий, ~40 мин: выбор ответа, TAK/NIE, сопоставление, открытые вопросы; записи из радио и ТВ | короткий польский ролик ≤ 8 мин на тему B2 + 5 вопросов по его тексту + пересказ | [sluchanie.md](sluchanie.md) | 🆕 v0.9 |
| **Czytanie** | 5 заданий, 60 мин: выбор, вставить фрагменты, сопоставление, TAK/NIE/brak informacji, клоуз; тексты из PAP, Onet, Interia, naTemat | свежая статья с бесплатного портала + 5 вопросов в экзаменационных форматах | [czytanie.md](czytanie.md) | 🆕 v0.9 |
| **Pisanie** | 2 текста ~300 слов: письмо, жалоба, рецензия, rozprawka… | пока внутри других: «своё предложение» в повторке, пересказ после слушания и чтения; письма — ближе к экзамену | — | ⏸ v5 (март) |

Каждый движок пишет в те же журналы: новые слова → [words.md](../words.md), ошибки → [errors.md](../errors.md), повторения → [reviews.md](../reviews.md), сессия → [log.md](../log.md) со строкой `- часть: …` — по ней `/b2` видит, какая часть давно не тренировалась.
