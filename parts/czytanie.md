# Движок «Czytanie» — свежая статья + вопросы

**Цель:** читать настоящие польские тексты того типа, что дают на экзамене (PAP, naTemat, Onet, Interia), на темы B2. 10–15 минут.

## 1. Найти текст (пользователь не ищет сам)

1. Свежие статьи: `.venv/bin/python tools/read.py feed naukawpolsce` или `… feed natemat` (бесплатно, без пейвола). Выбрать статью **за последнюю неделю**, по теме из `topics.md` или интересам из `profile.md`.
2. Другие бесплатные источники по темам — [sources/README.md](../sources/README.md), раздел «Чтение» (zdrowie.pap.pl, culture.pl, polska.travel, pulshr.pl…). **Платные (Polityka, Wyborcza, Rzeczpospolita) не брать.**
3. Текст: `.venv/bin/python tools/read.py text "<url>"`. Взять **300–700 слов**; длиннее — фрагмент из начала, связный.

## 2. Занятие

1. Ссылка + источник + одна строка «о чём». Текст пользователь читает по ссылке.
2. **5 вопросов**, форматы экзамена: выбор a/b/c · **TAK / NIE / BRAK INFORMACJI** · подобрать заголовок к абзацу · что значит слово в контексте · вывод автора. **Решить вслепую:** вопрос, на который можно ответить без текста, заменить; у каждого ответа — цитата-доказательство из текста.
3. Проверка сразу, для ✗ — цитата (1 строка).
4. **Своё мнение 2–3 предложениями** по теме статьи (письмо) — ошибки разобрать по правилам `/b2`.

## 3. Запись

- **log.md:** `- часть: czytanie` · статья (ссылка, источник, дата) · вопросы N/5 · мнение: ошибки (id).
- **words.md:** 2–3 слова из статьи с примером из текста → в лесенку.
- **errors.md / reviews.md:** ошибки из мнения — как в `/b2`.

**Почему так:** стандарт B2 требует понимать тексты по всем 18 темам, не только по интересам — поэтому тема берётся из необсуждённых подтем, а интерес — как угол.
