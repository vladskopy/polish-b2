# Движок «Słuchanie» — короткое видео + вопросы

**Цель:** привыкнуть к живой польской речи в темпе радио и ТВ, как на экзамене. 10–15 минут.

## 1. Найти ролик (пользователь не ищет сам)

1. Тема — одна необсуждённая подтема из `topics.md` (её даёт `draw.py`) или интерес из `profile.md`.
2. Поиск: `.venv/bin/python tools/listen.py search "<канал> <тема по-польски>"` — до 5 роликов **≤ 8 минут**.
3. Каналы, в порядке приоритета ([sources/README.md](../sources/README.md), раздел «Слушание»):
   - **polsatnews** (`polsatnews`), **TVP Info** (`TVP Info`) — новостные сюжеты 2–4 мин, как записи на экзамене; субтитры автоматические;
   - **Płynnie po polsku**, **Arlena Witt** — ручные польские субтитры, точный текст;
   - учебные: **Easy Polish** (уличные опросы).
4. Взять первый ролик с польскими субтитрами: `.venv/bin/python tools/listen.py subs "<url>"`. Субтитров нет — следующий ролик.

**Ограничение:** автосубтитры — распознавание речи, в них бывают ошибки (имена, числа, редкие слова). Вопросы строить только на том, что сказано ясно и повторяется в контексте; спорные места не спрашивать.

## 2. Занятие

1. Дать ссылку + одну строку контекста («сюжет polsatnews, 3:40, про очереди к врачам»). **Перед просмотром** — 3 ключевых слова, которые встретятся (с переводом).
2. Пользователь смотрит (можно дважды — на экзамене запись звучит 2 раза).
3. **5 вопросов**, форматы экзамена: выбор a/b/c · TAK/NIE · открытый вопрос (1–3 слова) · кто что сказал · что будет дальше. Ответы — по тексту субтитров, **решить вслепую**: если на вопрос можно ответить, не смотрев ролик, — заменить.
4. Проверка сразу, для ✗ — цитата из текста (1 строка) с таймкодом примерно.
5. **Пересказ 2–3 предложениями** (говорение/письмо) — ошибки разобрать в конце по правилам `/b2` (пропуск + подсказка, словарь, ✓/~).

## 3. Запись

- **log.md:** `- часть: słuchanie` · ролик (ссылка, длительность) · вопросы N/5 · пересказ: ошибки (id).
- **words.md:** 2–3 слова из ролика, которые стоит знать (с примером из ролика) → в лесенку повторения.
- **errors.md / reviews.md:** ошибки пересказа — как в `/b2`.
