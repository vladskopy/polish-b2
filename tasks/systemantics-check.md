# Чекпоинт: Systemantics, петли, сенсоры, подкрепление

**Когда:** каждые 5 сессий — `tools/draw.py` сам печатает строку ЧЕКПОИНТ. Занимает 5 минут: Claude готовит ответы по журналу, пользователь подтверждает или спорит.
**Зачем:** система не должна тихо уйти от своей цели. Основание — принципы Systemantics (Gall): простая работающая система, петли обратной связи, сенсоры, подкрепление.

## 1. Systemantics (Gall)

- [ ] **Проще, чем нужно, а не сложнее?** Что добавили с прошлого чекпоинта — и доказало ли оно пользу данными журнала?
- [ ] **Система «огрызается»?** Не начал ли пользователь обходить трудные конструкции, чтобы не копить ошибки? Не гонимся ли за X/122 вместо обучения?
- [ ] **Цель не уехала?** Всё ещё работаем на «60% в каждой части к 12.06.2027», а не на «приятный разговор»?
- [ ] **Одно изменение за раз.** Какое правило скилла поменяем (максимум одно) → новая версия в log.md.

## 2. Петли — замкнуты ли

| Петля | Проверить | Статус |
|---|---|---|
| Ответ → разбор | разбор читается; примеры полезны | |
| Память → жеребьёвка | старые ошибки реально возвращаются; сколько открытых ошибок (30+ → пора v3) | |
| Сомнительное → преподаватель → память | дошли ли ответы преподавателя обратно (правка A4) | |
| Система → улучшение | хватает ли данных в log.md, чтобы решить, что менять | |

## 3. Сенсоры — что видим и чего нет

- [ ] Оценки «зашло» за 5 сессий: среднее и тренд. Ранние выходы. Перерывы между сессиями.
- [ ] Длительность: держимся ли в 10–15 минутах.
- [ ] Крючки: доля «употребил верно». `grammar.md`: сколько «– обходишь» превратилось в ✓, растёт ли ↻.
- [ ] Сенсор грамматики: преподаватель проверяет 2–3 отметки G из reviews.md — верно ли Claude относит конструкции к пунктам.
- [ ] **Слепые зоны:** слушание, чтение, орфография при надиктовке, результат по частям экзамена (правка A6). Пора ли включать замер?
- [ ] Ошибки в окончаниях подозрительно редки? → часть ответов печатать (риск надиктовки).

## 4. Подкрепление

- [ ] Награда идёт за обучение (закрытые ошибки, слова употреблены снова), а не за отметки?
- [ ] Метрика бреда: сколько поправок Claude преподаватель счёл неверными.
