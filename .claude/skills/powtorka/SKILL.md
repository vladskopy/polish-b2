# Powtórka — тренировка своих ошибок

**Версия: v1.0.** История — [CHANGELOG.md](../../../CHANGELOG.md). Журналы общие с `/b2`: `errors.md`, `words.md`, `teacher.md`, `reviews.md`, `log.md`.

## Жёсткие правила

- **10–15 минут.** 3 ошибки + 2 слова. Не больше.
- **Пользователь ничего не выбирает.** Что тренировать, даёт `.venv/bin/python tools/draw.py --powtorka` — до 3 ошибок и 2 слов, которым **по лесенке пора повторить** (самые просроченные первыми). Пора меньше — блоков меньше, сессия короче; пора ничему — сказать и предложить новые темы.
- **Правило — 1 строка, дальше примеры и упражнения.** Никаких лекций.
- **Здесь проверка сразу** — после каждого блока, а не в конце: это режим «учимся».
- **Ответы коротко:** «1a 2c 3 *slowo* 4 …», голосом или текстом. Пунктуацию и заглавные из надиктовки не считать.
- **Контекст упражнений — мир пользователя:** интересы из `profile.md`.

## 1. Старт

1. `.venv/bin/python tools/draw.py --powtorka`. Запомни НАЧАЛО. Если есть строка ЧЕКПОИНТ — одной фразой предупреди.
2. Одной строкой: «Сегодня: E11, E12, E5 + 2 слова» — и сразу первый блок.

## 2. Блок на одну ошибку (×3)

1. **Напоминание:** сначала **твоя фраза** — строка ТВОЯ ФРАЗА из draw.py (это контекст, где была ошибка, уже в исправленном виде; неправильную версию не показывать). Потом правило в 1 строку и ещё 1 пример.
2. **4 упражнения**, форматы — как в экзаменационной грамматике («wpisz odpowiednią formę wyrazu z nawiasu»):
   - пропуск со словом в скобках — **два пункта**: `Liczba ___ (gość) rośnie.`;
   - выбор `a / b / c` — **твоя прошлая ошибочная форма среди вариантов не появляется**;
   - перестрой предложение (трансформация).
   Формата «найди и исправь ошибку» нет: неправильная форма не должна мелькать.
3. **Пятое — своё предложение** с этой конструкцией на заданную мини-тему.
4. **Проверка сразу:** по каждому пункту ✓ / ✗, для ✗ — верный ответ и 1 строка почему (только правильную форму, твой неверный ответ не повторять).

**Харнесс упражнений** (исследования: сгенерированные AI задания ошибочны в 20–50% случаев):
- перед показом реши каждый пункт заново, не глядя на свой ключ. **Если верных ответов несколько — это нормально** (решение пользователя 2026-10-13): принять любой верный и одной строкой объяснить разницу (*wdrożenie* — результат / *wdrażanie* — процесс). Заменить пункт, только если ответ спорный, а не просто не единственный;
- не строить пункты на формах, в которых не уверен; сомнение → `teacher.md`.
- **ключи — через словарь:** перед показом блока `.venv/bin/python tools/check.py "<все ответы блока>"`. Ответ-форма не найдена или её падеж/число/вид не те, что требует пункт, — заменить пункт. При проверке ✗ показывать доказательство одной строкой: `gości ← gość · мн · род.п`.

## 3. Слова (×2)

«Użyj w jednym zdaniu: *<słowo>* — o czymś z twoich zainteresowań» (интересы — из profile.md). Естественно и верно → ✓.

## 4. Итог

1. По ошибкам: `E11 4/5 ✓ · E12 3/5 ✓ · E5 2/5 ✗`; по словам: ✓ / ✗. После записи — ступени из `.venv/bin/python tools/srs.py`: «E11 ступень 1 → 2, вернётся 17.10».
2. Что закрепилось, что ещё нет — одной строкой.
3. Прогресс: ошибок закрыто X (открыто Y) · слов употреблено снова N;
4. строка грамматики из `.venv/bin/python tools/grammar.py` (после записи).
5. «Зашло? 1–5» (можно пропустить). Последней строкой — «Odhaczone ✓».

## 5. Запись (сам)

1. **errors.md:** блок пройден на 4/5 и выше → «верно» +1, дата. **В powtórka «верно» растёт максимум до 2** — закрывает ошибку только верное употребление в живом разговоре (`/b2`). Блок на 2/5 и ниже — ничего не менять, отметить в log.md.
2. **words.md:** ✓ → «употреблено» +1 и дата; ✗ → только дата.
3. **reviews.md:** **по строке на каждый пункт** — 5 на ошибку и по 1 на слово:
   `| ГГГГ-ММ-ДД ЧЧ:ММ | /powtorka | E11 | пропуск пункта: Liczba ___ (gość) | пропуск / выбор / трансформация / своё предложение / слово в предложении | ✓ или ✗ | если ✗ — какое правило не сработало (без неверной формы) |`
   Это фундамент для интервального повторения — ничего не пропускать.
4. **Новые ошибки из тренировки** (в своём предложении или ответе, не по теме блока) — **записывать как обычно**: новая строка E в errors.md (пропуск + подсказка, исправленный контекст, пункт G или «—»), строка `✗ своё предложение` в reviews.md; в итоге — строка «новое из твоих предложений».
4b. **teacher.md:** пункты, в которых сомневался.
4a. Выполни `.venv/bin/python tools/grammar.py` — строки E в reviews.md сами попадут в статистику по своему пункту G.
5. **log.md** (сверху):
   ```
   ## ГГГГ-ММ-ДД ЧЧ:ММ · powtórka · скилл v0.9
   - часть: gramatyka
   - запущена: ЧЧ:ММ · закончена: ЧЧ:ММ
   - ошибки: E11 4/5 (верно +1) · E12 3/5 · E5 2/5 — без ошибок: …; с ошибками: … (детали в reviews.md)
   - слова: W2 ✓ · W3 ✗
   - длительность: N мин · ранний выход: нет
   - зашло: 4/5 (или —)
   - заметка: одна строка
   ```
