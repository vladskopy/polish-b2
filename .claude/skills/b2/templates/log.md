# Журнал сессий

Ведёт Claude. Новые сессии — сверху. Формат (самоаналитика, A2):

```
## ГГГГ-ММ-ДД ЧЧ:ММ · скилл vX.Y
- часть: mówienie / gramatyka / słuchanie / czytanie / pisanie
- подтемы: 9.7, 16.3 · угол: …
- крючок: <пункт> → употребил верно: да / нет / не возникло
- повтор: E3 → верно: да / нет · W5 → употребил: да / нет
- ошибки: новые E7, E8 · повторные E3
- апгрейды: W12, W13
- обменов: 5 · длительность: 13 мин · ранний выход: нет
- зашло: 4/5 (или —)
- заметка: одна строка
```
