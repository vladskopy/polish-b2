# Журнал ошибок

Ведёт Claude после каждой сессии. Одна строка — один тип ошибки. Повторилась — «ошибок» +1. Использовал верно в новой сессии — «верно» +1. **Закрыта**, когда «верно» = 3. Упражнения в `/powtorka` дают «верно» максимум до 2 — третье только из живого разговора (`/b2`, новые темы), чтобы не закрывать ошибку одной тренировкой.

**Неправильная форма нигде не записывается** (решение 2026-10-13): ошибка хранится как пропуск с подсказкой в скобках — базовая форма или смысл по-русски — и верный ответ. **Контекст** — твоя фраза, где была ошибка, уже в исправленном виде. История каждого повторения — в `reviews.md`. **Грамматика** — пункт G из `grammar.md`, к которому относится ошибка; «—» для лексики, калек и орфографии.

В повторение попадают только поправки с меткой ✓. Сомнительное (~) — в `teacher.md`.
