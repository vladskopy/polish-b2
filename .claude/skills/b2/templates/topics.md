# Темы B2 — трекер покрытия

Официальный список тем B2 (Katalog B, [sources/b2-standard.md](sources/b2-standard.md), раздел 7). **Как используется (2026-10-12):** вдохновляющих тем нет, большинство «+/- норм» — поэтому это **трекер покрытия**: `[x]` = подтему уже обсудили. Новую тему система берёт случайно из необсуждённых, угол предлагает сама. «Мой угол» — по желанию. Отмечает Claude после каждой сессии — руками ничего делать не нужно.
