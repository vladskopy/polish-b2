# Nauczyciel — сводка к занятию с преподавателем

**Версия: v1.0.** История — [CHANGELOG.md](../../../CHANGELOG.md). JTBD: *когда готовлюсь к занятию раз в неделю — хочу в сжатой форме увидеть, что пошло хорошо и что нет, где ошибки и где прогресс с прошлого раза, чтобы занятие ушло на главное.*

Журнал сводок — [teacher-log.md](../../../teacher-log.md). Данные — общие журналы: [log.md](../../../log.md), [reviews.md](../../../reviews.md), [errors.md](../../../errors.md), [grammar.md](../../../grammar.md), [words.md](../../../words.md), [teacher.md](../../../teacher.md).

День занятий — `день занятий` в [profile.md](../../../profile.md); за день до него `/b2` сам предложит сводку.

Два режима: **до занятия** (по умолчанию) и **после занятия** (пользователь говорит «после занятия» / «препод сказал…»).

## А. До занятия — сводка

1. `.venv/bin/python tools/grammar.py`, потом `.venv/bin/python tools/teacher_report.py`. Работать **только по цифрам из отчёта** — ничего не додумывать.
2. Сводка — **один экран**, по-русски, без воды:

   ```
   ## К занятию ДД.ММ · период: с ДД.ММ (N сессий, оценки …)

   ✅ Хорошо: 2–3 пункта — грамматика ✓, исправившееся за период, слова, употреблённые снова
   ⚠️ Не очень: 2–3 пункта — ↻ повторяется, обходишь, новые ошибки (самые важные, не все)
   📈 С прошлой сводки: было → стало по 3–4 главным метрикам (в первый раз: «первый замер»)
   🎯 На занятие: 1–2 темы, на которые стоит потратить время — из ↻ и «обходишь»

   ❓ Pytania do nauczyciela (по-польски, чтобы зачитать или показать):
   1. …   ← открытые вопросы из teacher.md
   2. …   ← одна просьба по самому слабому звену: «Czy możemy przećwiczyć …?»
   3. Proszę sprawdzić: … ← 2 поправки Claude с ✓ для метрики доверия
   ```

   Ошибки — только как пропуск с ответом (`liczba ___ (gość)` → gości), **неправильную форму не показывать**. Исключение — вопросы из teacher.md: там нужен оригинал, иначе преподаватель не поймёт вопрос.
3. **Записать в teacher-log.md** сверху (под шапкой): сводку как есть + последней строкой `<!-- metrics: … -->` из отчёта — по ней следующая сводка посчитает «было → стало».

## Б. После занятия — ответы преподавателя

Пользователь коротко надиктовывает: «1 — ок, 2 — нет, правильно так…, 3 — …».

1. **teacher.md:** заполнить «ответ преподавателя» и «Claude был прав?» (да / нет / частично) по каждому пункту.
2. Если преподаватель поправил Claude — исправить запись в errors.md / words.md и в teacher.md в колонке «Claude был прав?» записать «нет — …»: что Claude утверждал и что оказалось верно.
3. Если преподаватель дал новое правило или тему — новая ошибка или слово по обычным правилам (пропуск + подсказка, контекст исправленный, пункт G).
4. В teacher-log.md под последней сводкой — блок `### После занятия ДД.ММ`: 2–4 строки — что разобрали, что поменяли.
5. Итог одной строкой — **метрика доверия** из отчёта: «преподаватель проверил N поправок Claude, верных M (X%)».
