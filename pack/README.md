# Polski B2 — подготовка к государственному экзамену в Claude Code

Подготовка к państwowy egzamin certyfikatowy z języka polskiego jako obcego (B2) **одной командой** — `/b2` в Claude Code. Ничего не нужно выбирать и помнить: система сама решает, что сегодня, проверяет себя по словарю и ведёт журналы.

## Что внутри

- **5 частей экзамена — 5 движков:** говорение (разговор по темам B2), грамматика (повторка своих ошибок), слушание (короткое польское видео + вопросы), чтение (свежая статья + вопросы), письмо (пока внутри других). Подробно — [parts/](parts/README.md).
- **Маршрут:** `/b2` смотрит долг интервального повторения и какие части давно не тренировались. Вайб — словом: `/b2 новое`, `/b2 повторка`, `/b2 слушать`, `/b2 читать`, `/b2 коротко`.
- **Интервальное повторение:** лесенка 1 → 3 → 7 → 21 → 60 дней по истории `reviews.md`.
- **Грамматика B2:** 108 пунктов официального стандарта; отчёт `grammar.md` — что выходит, где ошибки, что обходишь.
- **Проверка:** формы — по словарю Morfeusz 2 (SGJP, IPI PAN); сомнительное — преподавателю. Неправильные формы нигде не показываются — только пропуск с подсказкой и верный ответ.
- **Преподаватель:** `/nauczyciel` — сводка к занятию по-русски и вопросы по-польски; после занятия — метрика доверия к поправкам Claude.
- Официальные темы и грамматика B2 — [sources/b2-standard.md](sources/b2-standard.md) (Dz.U. 2025 poz. 217, Załącznik 1; тексты актов не охраняются авторским правом). Навигатор по материалам — [sources/README.md](sources/README.md).

## Установка

Нужно: [Claude Code](https://claude.com/claude-code), Python 3.10+, macOS или Linux. Желательно [uv](https://docs.astral.sh/uv/) — поставит нужный Python сам.

```bash
bash polish-b2-install.sh            # создаст папку polish-b2 рядом
bash polish-b2-install.sh ~/polski   # или в свою папку
```

Если установщик лежит по ссылке: `curl -fsSL <адрес>/polish-b2-install.sh | bash`.

Потом:

```bash
cd polish-b2 && claude
```

и в Claude Code — `/b2`. Первый раз будет короткий опросник (3–5 минут): уровень, сессия, интересы, как удобно отвечать, есть ли преподаватель. Из него получается `profile.md`.

## Команды

| Команда | Что делает |
|---|---|
| `/b2` | всё: сам выбирает повторку, разговор, слушание или чтение; первый запуск — профиль |
| `/powtorka` | сразу повторка своих ошибок |
| `/nauczyciel` | сводка к занятию с преподавателем; «после занятия» — внести его ответы |

## Твои данные

Создаются при первом `/b2` и живут только в твоей папке: `profile.md`, `errors.md`, `words.md`, `reviews.md`, `log.md`, `topics.md`, `grammar.md`, `teacher.md`, `teacher-log.md`. В пакет они не входят, повторная установка их не трогает.

Наружу уходит только: адрес статьи — в читалку r.jina.ai (чтение), поисковый запрос — на YouTube через yt-dlp (слушание). Твои ответы видит Claude — как в любой сессии Claude Code.

## Обновление

Запусти новый установщик в ту же папку — системные файлы обновятся, данные останутся.

## Честно об ограничениях

- Правила экзамена на 2027 год ещё не опубликованы (ожидаются в IV кв. 2026) — формат частей может измениться.
- Автосубтитры YouTube содержат ошибки распознавания; вопросы к видео строятся только по ясно сказанному.
- Поправки и вопросы генерирует AI: формы проверяются словарём, но употребление и смысл — нет. Преподаватель остаётся арбитром.
