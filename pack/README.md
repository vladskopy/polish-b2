# Polski B2 — подготовка к госэкзамену по польскому прямо в Claude Code

**Что это.** Набор скиллов и маленьких скриптов для [Claude Code](https://claude.com/claude-code), который превращает его в ежедневного тренера к государственному экзамену по польскому как иностранному (*państwowy egzamin certyfikatowy*, уровень B2). Одна команда — `/b2` — и 10–15 минут практики.

**Идея.** Это **дополнение к занятиям с преподавателем, а не замена.** Преподаватель раз в неделю — живой разговор и финальное слово. Между занятиями — практика здесь же, в Claude Code, где многие и так сидят весь день: не нужно открывать отдельные приложения, вести тетради и помнить, что повторять. Claude делает то, в чём он силён — придумывает задания под твои интересы, разбирает ошибки, помнит всё и подстраивается, — а рутину (что сегодня, что повторить, что спросить у преподавателя) система берёт на себя.

**Для кого.** Ты готовишься к B2 (или около того), уже немного говоришь по-польски, пользуешься Claude Code и хочешь системности без зубрёжки учебников. Не подойдёт, если ты учишь польский с нуля: система рассчитана на уровень, на котором уже можно разговаривать.

Почему устроено именно так — сценарии в [JTBD.md](JTBD.md).

## Как выглядит занятие

```
> /b2
Долгов нет, чтения ещё не было → сегодня статья. Хочешь другое — скажи «новое» или «повторка».

Nauka w Polsce, 13.10: «…» — 5 вопросов: TAK / NIE / BRAK INFORMACJI, выбор, слово в контексте.
…ответы голосом или «1 tak 2 b 3 …»…
Разбор: ошибки по темам (без неправильной формы — пропуск с подсказкой и ответ),
2–3 новых слова в копилку, итог: закрыто ошибок · слов употреблено снова · темы X/122.
Odhaczone ✓
```

## Что внутри

| | |
|---|---|
| **5 частей экзамена — 5 движков** | говорение (разговор по 2 темам B2 с грамматическим крючком), грамматика (повторка своих ошибок в формате экзамена), слушание (польское видео ≤ 8 мин + вопросы), чтение (свежая статья с бесплатного портала + вопросы), письмо (пока внутри других). [parts/](parts/README.md) |
| **Маршрут** | `/b2` смотрит долг повторения и какие части давно не тренировались; вайб — словом: `/b2 новое`, `повторка`, `слушать`, `читать`, `коротко` |
| **Интервальное повторение** | лесенка 1 → 3 → 7 → 21 → 60 дней по истории каждой ошибки и слова |
| **Грамматика B2** | 108 пунктов официального стандарта; отчёт: что выходит, где ошибки, что повторяется, что обходишь; крючок — из слабого звена |
| **Проверка** | формы — по словарю Morfeusz 2 (SGJP, IPI PAN) с доказательством; сомнительное — преподавателю |
| **Преподаватель** | `/nauczyciel`: сжатая сводка к занятию и вопросы по-польски; после занятия — его ответы и метрика доверия к поправкам Claude |
| **Профиль** | адаптивный: интересы, как отвечаешь, что не делать; дополняется по ходу занятий |
| **Источники** | официальный стандарт B2 — [sources/b2-standard.md](sources/b2-standard.md); навигатор по легальным материалам (бесплатное и платное помечено) — [sources/README.md](sources/README.md) |

## Установка

Нужно: Claude Code и Python 3.10+. Желательно [uv](https://docs.astral.sh/uv/) — поставит нужный Python сам.

**Системы** (проверяется CI на каждом изменении): macOS · Linux · Windows (установщик — в **Git Bash**, он ставится вместе с Claude Code). На Linux ARM (Raspberry Pi и т.п.) нет словаря Morfeusz — проверка форм не работает, остальное работает.

```bash
curl -fsSL https://github.com/vladskopy/polish-b2/releases/latest/download/polish-b2-install.sh | bash
```

Или скачать `polish-b2-install.sh` со [страницы релизов](https://github.com/vladskopy/polish-b2/releases) и запустить `bash polish-b2-install.sh` (или `bash polish-b2-install.sh ~/polski` — в свою папку).

Потом `cd polish-b2 && claude` и в Claude Code — `/b2`. Первый раз будет короткий опросник (3–5 минут): уровень, сессия, интересы, как удобно отвечать, есть ли преподаватель и в какой день.

## Команды

| Команда | Что делает |
|---|---|
| `/b2` | всё: сам выбирает повторку, разговор, слушание или чтение; первый запуск — профиль |
| `/powtorka` | сразу повторка своих ошибок |
| `/nauczyciel` | сводка к занятию с преподавателем; «после занятия» — внести его ответы |

## Твои данные и приватность

Создаются при первом `/b2` и живут только в твоей папке: `profile.md`, `errors.md`, `words.md`, `reviews.md`, `log.md`, `topics.md`, `grammar.md`, `teacher.md`, `teacher-log.md`. Это обычные md-файлы — их можно открыть, поправить, удалить. В пакет они не входят, повторная установка их не трогает.

Наружу уходит только: адрес статьи — в читалку r.jina.ai (чтение), поисковый запрос — на YouTube через yt-dlp (слушание). Твои ответы видит Claude — как в любой сессии Claude Code.

## Как устроено

Скиллы — инструкции для Claude в `.claude/skills/` (`b2`, `powtorka`, `nauczyciel`). Всё, что должно быть точным, — скрипты в `tools/`: случайный выбор тем (`draw.py`), лесенка повторения (`srs.py`), грамматическая статистика (`grammar.py`), словарь (`check.py`), видео (`listen.py`), статьи (`read.py`), сводка (`teacher_report.py`). Хранилище — md-таблицы, без базы данных. Раз в 5 сессий — самопроверка по принципам Systemantics ([tasks/systemantics-check.md](tasks/systemantics-check.md)). История — [CHANGELOG.md](CHANGELOG.md).

## Обновление

Запусти новый установщик в ту же папку — системные файлы обновятся, данные останутся.

## Честно об ограничениях

- Правила экзамена на 2027 год ещё не опубликованы (ожидаются в IV кв. 2026) — формат частей может измениться.
- Автосубтитры YouTube содержат ошибки распознавания; вопросы к видео строятся только по ясно сказанному.
- Поправки и задания генерирует AI: формы проверяются словарём, но употребление и смысл — нет. Преподаватель остаётся арбитром.
- Сценарии выросли из опыта одного человека (n = 1) — см. [JTBD.md](JTBD.md).
